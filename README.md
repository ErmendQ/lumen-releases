# Lumgraph

Downloads for Lumgraph, a canvas for planning projects. The app's source code lives elsewhere; this repo only
holds the finished builds.

## Download

- **Windows:** [Lumgraph-Windows-Setup.exe](https://github.com/ErmendQ/lumen-releases/releases/latest/download/Lumgraph-Windows-Setup.exe)
- **Mac (Apple silicon):** [Lumgraph-Mac.dmg](https://github.com/ErmendQ/lumen-releases/releases/latest/download/Lumgraph-Mac.dmg)

These links always serve the newest version. Older versions are listed under
[Releases](https://github.com/ErmendQ/lumen-releases/releases).

**Mac:** open the disk image and drag Lumgraph onto Applications. The first time, right-click Lumgraph and choose
Open (the app isn't notarized by Apple yet).

## Updates

Lumgraph checks for updates by itself when it starts, and in Settings > Updates. Updates are signed: the app only
installs ones signed with Lumgraph's own key.
