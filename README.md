# Lumen

Downloads for Lumen, a canvas for planning projects. The app's source code lives elsewhere; this repo only
holds the finished builds.

## Download

- **Windows:** [Lumen-Windows-Setup.exe](https://github.com/ErmendQ/lumen-releases/releases/latest/download/Lumen-Windows-Setup.exe)
- **Mac (Apple silicon):** [Lumen-Mac.dmg](https://github.com/ErmendQ/lumen-releases/releases/latest/download/Lumen-Mac.dmg)

These links always serve the newest version. Older versions are listed under
[Releases](https://github.com/ErmendQ/lumen-releases/releases).

**Mac:** open the disk image and drag Lumen onto Applications. The first time, right-click Lumen and choose
Open (the app isn't notarized by Apple yet).

## Updates

Lumen checks for updates by itself when it starts, and in Settings > Updates. Updates are signed: the app only
installs ones signed with Lumen's own key.
